# Lineage: A Collaboration

**WISDOM chooses. LINEAGE remembers why.**

This repository hosts **Project Codex of Troy**, the first mutation event in the UDD Cinematic & Media Universe.

The project explores how independent human-AI teams preserve evidence, uncertainty, provenance and useful action when context is ambiguous or unstable.

## Operating rule

Source evidence remains immutable. Mutations are isolated, declared and traceable. ZERO, NULL, UNOBSERVED, CONFLICT and RESIDUAL are distinct states. `WISDOM` marks intentional participation. It does not authenticate identity or grant authority.
